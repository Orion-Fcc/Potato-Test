# 依赖锁文件（2026-10-20，P0-1）
#
# 用法（CI 与本地打包同一份）：
#     pip install -c constraints.txt -e ".[dev,desktop]"
#
# ## 为什么锁的是"直接依赖"而不是 `pip freeze` 全量
#
# 本机 venv 里有两个包是从**本地 wheel** 装的（`opencv-python-headless`、
# `tokenizers` 的 `@ file:///C:/tmp/...`），把它们原样冻进锁文件会让别的机器
# 去一个不存在的路径找文件；而 venv 里还混着一堆只在本机装过、与项目无关的包
# （anthropic / google-genai / mcp ...）。全量 freeze 既不能跨平台，也不表达
# "项目到底依赖什么"。
#
# 这里锁住 `pyproject.toml` 声明的**每一个直接依赖**到本机验证过的版本，
# 传递依赖仍由 pip 解析（`pip check` 会在 CI 里检查冲突）。新增直接依赖时
# `tests/test_dependency_lock.py` 会失败，提醒你把版本补进来。
#
# 升级某个包：改 pyproject 的范围 → 在干净环境装上 → 用 `pip show` 的实际版本
# 更新这里的 `==` → 跑测试与打包冒烟。
