## 一、跑之前：先把服务起来

1. 双击桌面 `PotatoTest.bat` → 菜单 **1（启动）**。
   - 改过代码/配置必须走这个重启，让新代码生效。
   - 服务后台常驻，关黑窗口不停；再双击一次进 **2（关闭）**。
2. 浏览器开 <http://127.0.0.1:18081/>。
3. 进对应项目（飞行学员管理 / 培训资源管理）。

---

## 二、看失败清单（知道"现在该做什么"）

入口：**项目 → 概览** 页，最上面那张卡片就是**失败清单**。

### 1. 读清单

- 卡片标题行右侧有计数：`未通过 N · 归为 M 类原因 · X 条待人工确认`。
- 每个**分组**是一个"相同原因"的批次，展开（点 `+`）能看：
  - **动作徽章**（该做什么）：
    - 红色 `提缺陷` → 找开发（只有"产品缺陷"走这里）
    - 蓝色 `改用例` / `修数据` → 改用例或补数据
    - 黄色 `查环境` / `人工判断` → 环境或根因冲突
    - 灰色 `重跑` → 直接重跑即可
  - 组内每条用例：`用例号 名称`，失败多次会标 `（失败 N 次）`，下面一行是最近一次的判定理由。
- 看到 **`根因冲突，需人工判断`** 的组：同一组里判定器给出了不同根因，**已按人工确认处理**，别按"多数决定动作"。

### 2. 补全分类（点一下才花额度）

- 右上角 **「补全分类」** 按钮会调 LLM 给历史没分好类的结果补 `root_cause`，**结果落库缓存**，之后不会重复调。
- **默认进页面是不点它的**（首屏快、省额度）。只有看到"待人工确认"偏多、或想让分组更细时再点。
- 点完变 `正在补分类…`，十几秒内回来。某条分类明显不对，清掉该条缓存重新回填即可。

### 3. 清单是自动的，别手工维护

- 清单是**派生视图**：某条用例一旦通过，自动从这里消失。
- 合并靠确定性证据（同因才合），**不做"按标题相似度"的二次合并**——合并错比不合并不糟，人会照着清单查一个不存在的问题。

## 三、让助手按清单改用例（改动留痕）

1. 进 **助手** 页，直接说自然语言，例如：
   > `按失败清单把该改的用例改掉`
2. 助手读清单 → 只对"改用例"类动作动手 → 通过 `x-change-source: assistant` 改用例。
3. 改动**自动写进审计表 `case_change`**，记录：改了哪个字段、改前、改后、谁改的、来自哪条清单。
4. 用例**跑通之后**，对应清单分组自动消失（见第二节第 3 点），不需要你去删。

### 查改动记录（审计）

目前**没有界面入口，走接口**（`case-changes` 只有 API，前端尚未挂面板）：

```
GET http://127.0.0.1:18081/api/projects/{pid}/case-changes?limit=100
```

- `{pid}` 填项目 id；`limit` 默认 100。
- 返回 `case_change` 记录列表，可核对"助手到底改了什么"。

## 五、判定更严了，怎么看"通过/失败"更可信

这轮加了防"假通过 / 假缺陷"的确定性校验，你不需要做任何操作，但要知道**判定口径变了**：

| 现象 | 现在会怎样 |
| - | - |
| agent 结论里写"查询后应有 N 条"，但步骤里从没真读过查询结果 | 判 **failed**，理由写"未测到"，不算缺陷 |
| 最后一步 `action=done` 但同一步还在执行中 | 判 **执行未完成**，不算产品缺陷 |
| 整段都是工具回显、没结论 | 判 **证据不足** |
| agent 一遇障碍就说"无法完成"就停 | 提示词已治住：会换路多试，不再第 1 步就放弃 |

- 想看判定细节：结果里折叠的 **Judge / Final answer**，看"判定理由 + 依据步骤 + 最终回答"。
- 拿那条老被误判的**"使用范围 + 状态同时选 → 点查询"**做试金石：操作对的话，现在不该再被判错。

## 六、出问题的快速定位

| 症状 | 先看这里 |
| - | - |
| 页面打不开 | `logs/potato.log` 最后几行；端口是否 18081 |
| 跑用例报"找不到浏览器" | 系统 Edge 没被探测到；`跑批前体检.bat` 过一遍 |
| 整批用例全 error、无结论 | 历史回归是 `await` 同步 sleep，现已修；若复现看日志有无 `TypeError: ... await` |
| 429 / 网关报错 | LLM 额度耗尽，代码层不解决，跑大批量前留意额度 |
| 清单"几乎没合并" | 点一次「补全分类」补根因，再刷 |
